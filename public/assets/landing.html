Architecture & Capabilities

Built for systems where daemons are a liability.

Elasticsearch, Promtail, and Vector eat hundreds of megabytes of RAM. LogPulse runs on standard shared hosting with zero persistent memory footprint.

01

Project-Centric Isolation

Organize telemetry by application (e.g. Audiobookshelf, Nextcloud, Stripe Gateway). Each project gets an independent high-entropy ingest token, custom retention schedule, and dedicated log stream.

02

Real-Time AJAX Streaming

Shared Apache servers terminate long-lived WebSockets and SSE connections after 30 seconds. LogPulse uses low-overhead, cursor-based short polling (1s-10s) with pause/resume controls that never drop.

03

Slide-Over Event Inspector

Click any log row in the dashboard to slide out formatted JSON contexts, raw request bodies, caller IP addresses, user agents, and exact millisecond event timing.

04

Synthetic Health Pings

Probe your public URLs or internal APIs on a schedule. Track HTTP status codes and response latency over time with visual health badges right on each project card.

05

Threshold Alert Engine

Trigger notifications to Discord, Slack, custom HTTP webhooks, or email when the error count for an endpoint crosses your configured threshold in any sliding time window.

06

Cron-Driven Automation

Background tasks (retention pruning, alert evaluation, uptime probes) run cleanly via a single standard cPanel cron command: php bin/console cron:run.
