LogPulse API Specification

REST API for real-time log ingestion, project management, and automated synthetic monitoring. Built for zero-dependency shared hosting and cloud servers.

Base URL
https://logs.yourdomain.com/api/v1

Authentication

LogPulse uses two distinct authentication tokens:

User JWT (Bearer)

Used for managing projects, alerts, and viewing log streams. Obtained via /api/v1/auth/login.

Authorization: Bearer <jwt_token>
Ingest Token (lp_*)

Unique per project. Senders use this to submit logs via URL path or HTTP header.

POST /api/v1/ingest/lp_2bfbf...
POST /api/v1/auth/login
Public
Request Body:
{
  "email": "admin@logpulse.io",
  "password": "AdminSecret2026!"
}
Response (200 OK):
{
  "success": true,
  "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
  "user": {
    "id": 1,
    "name": "Ayush Lead SRE",
    "email": "admin@logpulse.io",
    "role": "admin"
  }
}

GET /api/v1/projects
Requires Bearer JWT
Returns all projects with log count, 24h error counts, and latest health check latency.

Log Ingestion API (Dual Auth)

High-throughput JSON log ingestion. Supports single log objects or batch arrays up to 500 items per request.

POST /api/v1/ingest/{token}
Option A: URL Token
Option B: Header Authentication:
POST /api/v1/ingest
Authorization: Bearer <ingest_token>
X-API-Key: <ingest_token>
Payload Envelope (Single or Batch):
[
  {
    "level": "INFO",
    "message": "User session authenticated",
    "context": { "user_id": 481, "role": "admin" },
    "timestamp": "2026-09-24T03:57:00Z"
  },
  {
    "level": "ERROR",
    "message": "FFmpegTranscodeException: Failed to encode stream",
    "context": { "codec": "aac", "file": "Dune.m4b" }
  }
]
Response (200 OK):
{
  "success": true,
  "ingested": 2,
  "endpoint": "audiobookshelf"
}

Log Query & Inspector API

GET /api/v1/logs
Requires Bearer JWT
Query Parameters:
  • endpoint_id (int): Filter to specific project ID
  • level (string): Filter by level (INFO, WARN, ERROR, DEBUG)
  • q (string): Full-text grep search on message
  • since_id (int): Fetch records with id > since_id for streaming delta
  • limit (int): Records per page (default 50, max 200)
